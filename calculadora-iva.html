Cómo se calcula el IVA

Para añadir el IVA se multiplica la base por el tipo: una base de 100 € al 21 % tiene 21 € de IVA y un total de 121 €.

Para quitar el IVA de un precio final no se resta el 21 %: se divide entre 1,21. Un precio de 121 € con IVA incluido tiene una base de 100 €.

La retención de IRPF se calcula sobre la base, no sobre el total. En una factura de 1.000 € de base con 21 % de IVA y 15 % de IRPF, el cliente paga 1.060 €: 1.000 + 210 − 150.
